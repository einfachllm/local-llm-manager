Import from script or docker run

      

        
Paste a starter script or a docker run … command. It is first checked for unusual
          calls (nothing is executed), then run by bash on the Spark in a restricted mode: only read-only text tools
          (awk, sed, grep, cut, date, …) really run, a fake
          docker records the final docker run command, and every other command is
          recorded and skipped.
